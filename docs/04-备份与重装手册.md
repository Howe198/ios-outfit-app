# 备份与重装手册

> 对应规划书第 12 页 6.4。目标：不看代码、只看这份说明，就能完成一次重装与恢复。
> **免费个人签名到期后 App 会打不开，这是签名过期，不是数据丢失。** 重装前先备份。

## 1. 备份存在哪里

| 项 | 位置 |
| --- | --- |
| App 内备份目录 | `Documents/Backups/衣橱备份-yyyyMMdd-HHmm.zip` |
| 在 iPhone 上怎么看 | 「文件」App → 浏览 → 我的 iPhone → 衣橱穿搭 → Backups |
| zip 内容 | `backup.json`（全部记录）+ `images/`（全部照片） |

> 备份是单个 zip，可以直接 AirDrop 到 Mac、存进 iCloud Drive 或发给自己。

## 2. 什么时候导出

- 录完一批新衣物后；
- 每次系统大版本升级前；
- 免费签名快到期前（建议到期前 2 天）；
- 要做任何"删除"操作前（删衣物、删搭配、导入覆盖）。

导出步骤：日历与我的 → 我的 → 「导出备份」→ 出现分享按钮后，把 zip 传到 Mac 或 iCloud Drive。

## 3. 免费签名到期怎么办

现象：某天点开 App 图标，闪一下退出，或提示「无法验证 App」。

原因：个人签名有效期到期（通常约 7 天，具体以 Xcode 当时提示为准）。

处理：

1. iPhone 连 Mac，信任此电脑；
2. Xcode 打开 `OutfitApp.xcodeproj`，选中真机，点 Run；
3. Xcode 会重新签名并安装，**覆盖安装通常保留数据**；
4. 如果被要求先删除 App，先确认已导出备份，再重装并用第 5 节恢复。

## 4. 全新重装（换机或重装系统）

1. 在旧设备导出备份，传到新设备可访问的位置（iCloud Drive / 文件 App / AirDrop）；
2. Mac 上 Xcode 打开工程，选自己的 Team，Bundle ID 保持或改成新的唯一值；
3. 连新 iPhone，Run 安装；
4. 首次启动信任开发者：设置 → 通用 → VPN 与设备管理 → 信任；
5. 打开 App → 日历与我的 → 我的 → 「导入备份并恢复」；
6. 选择那个 zip → 确认「覆盖并恢复」；
7. 核对提示里的件数、图片数与旧设备一致。

## 5. 导入恢复会发生什么

- 先完整读取 zip、校验每个文件（CRC），再解析 `backup.json`；
- 全部校验通过后才清空当前数据并写入；
- 所有内部 ID 会重新生成，搭配、记录、灵感之间的引用会自动重新指向；
- 校验或写入失败时给出错误提示，不会留下"删了一半"的状态。

所以：**导入是覆盖式的**。如果当前设备已有新数据，先导出一次再导入。

## 6. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打开 App 闪退 | 签名过期 | 连 Mac 重新 Run |
| 恢复后图片缺失 | zip 里 `images/` 不完整 | 用更早一份备份重新导入；图片缺失不影响记录 |
| 导入提示「不是本 App 的备份文件」 | zip 内没有 `backup.json` | 确认选的是「衣橱备份-*.zip」，不是手机相册导出的压缩包 |
| 导入提示「备份文件损坏」 | zip 传输中损坏 | 重新传一次，或换一份备份 |
| 文件 App 里看不到 App 目录 | 系统未刷新 | 关闭再打开「文件」App；仍看不到就用「分享刚导出的备份文件」按钮 |
| 换机后搭配里少衣物 | 备份里该衣物已被删除 | 正常现象，删除衣物时引用已同步清理 |
