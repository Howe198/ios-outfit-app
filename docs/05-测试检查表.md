## 5.2 推荐质量抽检

温度取实际天气，选冷 / 适中 / 热三档各一天，两个常用场合各抽一次，共 6 组：

| 组 | 温度档 | 场合 | 出套数 | 能否直接穿出门 | 问题 |

| 1 | 冷 | 通勤上班 |  |  |  |

| 3 | 适中 | 通勤上班 |  |  |  |
| 4 | 适中 | 日常休闲 |  |  |  |
| 5 | 热 | 通勤上班 |  |  |  |
| 6 | 热 | 日常休闲 |  |  |  |

判定口径：

- 6 组都给出完整搭配，无"半套"；
- 无归档衣物、无当季明显不合理的单品（如热天羽绒服）；
- 每套理由都能对应到实物（颜色、近期没穿、场合匹配）。

**不合适的先改规则，不要靠手动删结果掩盖。**
