## 3. P0 冻结（0.2）

功能范围与规划书第 3 页完全一致，**未增未减**：

1. 衣物库（拍照/录入、分类、颜色、季节、场合标签）
2. 每日推荐（按气温 + 场合，从已有衣物组 1–3 套）
3. 手动组套（自己搭配并保存成套）
4. 今日穿搭记录（一天一条，可改，日历回看）
5. 灵感收藏（手动存图 + 提炼要点，不做抓取）
6. 数据导出恢复（本地 zip，含 JSON 与图片）

不做清单（写进代码边界，不实现）：

- 账号体系、社区、关注、点赞、商城、二手交易
- 付费 AI 识别、付费抠图、付费天气接口、任何订阅制服务
- 自动抓取小红书/杂志内容
- 上架 App Store、多人协作、Android 版
- P1（穿搭统计、胶囊衣橱、打包清单、桌面小组件）与 P2（试穿合成、购物建议、多设备同步）

## 4. 页面地图与主路径（3.1）

```
今日 ──生成推荐──▶ 记今日穿搭 ──▶ 日历（回看）
  │
  └─切到衣橱（补单品）
衣橱 ──▶ 衣物详情 ──▶ 编辑 / 归档 / 删除
  └─+ 新增（拍照 → 字段 → 保存）
搭配 ──我的搭配──▶ 新建/编辑 ──▶ 设为今日穿搭
  └──灵感收藏──▶ 新建 ──▶ 提炼为规则
日历与我的 ──▶ 我的 ──▶ 规则 / 标签词表 / 导出导入
```

- 主路径步数：打开 → 生成 → 记录 = 3 步（今日页首屏即可完成）。
- 每页都能回到今日：底部分页常驻，子页均有返回。

## 5. 空状态与异常提示文案（3.3）

| 场景 | 文案 | 下一步出口 |
| --- | --- | --- |
| 衣橱为空 | 「衣橱还是空的。先按阶段 1 的拍照规范录入 5 件试试。」 | 「添加第一件衣物」按钮 |
| 无符合规则的搭配 | 「没有匹配「X」的衣物，或有单品的温度、季节与当前条件不符。」 | 提示调整温度档 / 换场合 / 补单品 |
| 冷天缺外套 | 「今天偏冷，一套搭配需要外套，但衣橱里没有适合这个温度的外套。」 | 去衣橱添加，或把温度调高一档 |
| 图片缺失 | 占位图 +「图片缺失」 | 进衣物详情重新上传 |
| 备份无效 | 「zip 里没有 backup.json，不是本 App 的备份文件」 | 重选文件 |

## 6. 五组标签词表（0.4）

| 组 | 词表（每组 ≤12） | 说明 |
| --- | --- | --- |
| 品类 | 上装、下装、外套、一体、鞋、配饰 | 连衣裙/连体归「一体」 |
| 主色 | 黑、白、灰、米、棕、驼、藏青、蓝、绿、红、粉、黄 | 只填面积最大的一个；拼色写备注 |
| 季节 | 春、夏、秋、冬 | 按实际可穿季节，不按购买季节 |
| 场合 | 通勤上班、日常休闲、运动健身、正式场合、居家 | 默认常用：通勤上班、日常休闲（待确认） |
| 厚度 | 薄、中、厚 | 用于温度完整性判断 |

颜色分组（仅用于「颜色协调」打分）：

- 中性色：黑 / 白 / 灰 / 米 / 棕 / 驼
- 暖色：红 / 粉 / 黄
- 冷色：藏青 / 蓝 / 绿
