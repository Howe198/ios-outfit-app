# 推荐规则说明

> 对应规划书第 8 页（阶段 2）与第 10 页 4.3。实现位置：`OutfitApp/Services/RecommendationEngine.swift`。
> 目标：每套推荐都能说清「为什么推这套」，不出现黑盒结果。

## 0. 温度档

温度来源（2026-11-26 起）：优先用设备定位向免费 Open-Meteo 接口取当前气温（无需 key，坐标只在内存中用一次，不保存、不上传）；没有定位权限或断网时回落到手动输入摄氏温度。档位划分不变：

| 档位 | 范围 |
| --- | --- |
| 冷 | ≤10℃ |
| 适中 | 11–22℃ |
| 热 | ≥23℃ |

档位用于两处：完整性判断（冷天必须有外套）、季节匹配（冷→冬/秋，适中→春/秋，热→夏/春）。

## 1. 第一层：硬性排除（2.1）

满足任一条件即不进候选池：

| 规则 | 判定 |
| --- | --- |
| 状态 | 状态为「归档」 |
| 季节 | 衣物季节集合与当前档位对应季节无交集 |
| 温度 | 填了个人温度区间，且当前温度超出区间 ±3℃ |
| 厚度 | 热档 + 厚料 |
| 自定义排除 | 用户建了「排除」类规则且命中该衣物 |

> 反例验证：把一件夏装、一件归档外套、一件标了 ≤5℃ 的毛衣放进衣橱，推荐里都不应出现。

## 2. 第二层：完整性（2.2）

一套必须能穿出门：

- 一体类（连衣裙/连体裤）：单独成一套，可再加外套；
- 其余：**上装 + 下装** 缺一不可；
- 冷档：**必须有一件外套**，没有可用外套时不出套，直接给提示；
- 鞋：**可选**（附录B 待确认）；有可用鞋时自动配一双；
- 配饰：不参与完整性判断，只参与打分。

## 3. 第三层：打分（2.3）

全整数，无小数，便于解释。每套得分 = 下列各项之和：

| 项 | 条件 | 分值 | 理由文案示例 |
| --- | --- | --- | --- |
| 颜色协调 | 主色同属一个色系 | +3 | 颜色同属一个色系 +3 |
| | 含中性色（黑/白/灰/米/棕/驼）且不超过 2 个色系 | +2 | 中性色打底，配色稳 +2 |
| | 两个非中性色系混搭（暖+冷） | 0 | 冷暖色混搭 +0 |
| | 3 个以上色系 | +1 | 颜色较杂，但不算冲突 +1 |
| 近期未穿 | 全套近 7 天都没穿过 | +3 | 近 7 天都没穿过 +3 |
| | 近 7 天穿过 1 件 | +1 | 近 7 天穿过 1 件 +1 |
| 场合匹配 | 全部单品都带当前场合标签 | +2 | 场合全部匹配「通勤上班」+2 |
| | 部分匹配 | +1 | 部分单品匹配「通勤上班」+1 |
| 收藏优先 | 含「收藏」搭配里的单品 | +2 | 含收藏搭配里的单品 +2 |
| 自定义规则 | 命中加分 / 减分规则 | ±N | 规则「黑白配更稳」+2 |

结果按得分降序，去重后最多保留 12 套；今日页每页展示 3 套，「换一套」翻页。

## 4. 自定义规则（2.5）

- 类型：排除 / 加分 / 减分；
- 作用维度：品类、主色、场合、季节、厚度、指定衣物；
- 每条规则可随时开关；停用只影响之后的推荐，不改历史记录；
- 从灵感提炼时，自动记录来源灵感 ID 与启用日期（`createdAt`）；
- 建议每次只启用 1–2 条新规则，观察一周再决定保留，否则分不清哪条起作用。

## 5. 灵感收藏规范（2.4）

一条合格的灵感必须满足：

1. 图片是**本人手动保存**的（截图或相册选择），不做自动抓取；
2. 有**一句可借鉴点**，写成能照着穿的动作，例如「灰蓝叠穿时，内浅外深」；
3. **至少关联 1 件自有衣物**（表单强制）；
4. 记录来源平台与日期（可选，但建议填）。

不合格的灵感（只有图、没有要点、没有对应衣物）不入库。

## 6. 为什么不用 AI 推荐

- 个人衣物量小，规则足够；
- 规则可解释、可离线、可随时改权重；
- 不产生任何 API 费用，也不上传照片。

代价是：不擅长「风格创意」，只擅长「在已有衣物里挑出合理组合」。风格灵感通过「灵感收藏 → 提炼规则」补足。

## 7. 需要修正时的入口

| 想改什么 | 改哪里 |
| --- | --- |
| 温度档边界 | `TempBand.from(celsius:)` |
| 排除条件 | `recommend(...)` 中 `usable` 的过滤段 |
| 打分权重 | `evaluate(...)` |
| 每页套数 / 总套数 | `limit` 与今日页 `page * 3` |
| 加规则 | App 内「我的 → 穿搭规则」，不用改代码 |
