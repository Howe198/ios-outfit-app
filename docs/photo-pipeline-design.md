# 照片流水线实现方案（第二批任务书 5–7 与条目 6）

## 一、可用的原生能力与边界

- 人物检测：`VNDetectHumanRectanglesRequest`。多人时只用于出选择框，不判断穿着。
- 人体关键点：`VNDetectHumanBodyPoseRequest`（颈、肩、髋、膝、踝）。用于确定上装/下装的几何范围。
- 人像分割：`VNGeneratePersonSegmentationRequest`（iOS 17，本机、免费）。只区分「人 / 背景」，没有「衣服 / 皮肤」的语义。
- 系统没有人像衣物语义分割模型；本 PR 不下载第三方模型（避免体积、许可证与费用不确定）。

结论：本机只能做「姿态区域 + 人像遮罩 + 几何裁剪」的近似衣物提取，不是完美的服装语义分割。这个限制会写进 PR 和界面提示，不夸大为「精准抠衣服」。

## 二、5(a) 多人选人

1. 选照片后先跑 `VNDetectHumanRectanglesRequest`（`upperBodyOnly = false`）。
2. 检测到 2 个及以上人物框：弹出人物选择页，原图上叠加半透明选框，用户点选一个人。
3. 选中后把该人框适度外扩后裁出，再进入后续流水线；单人或检测不到人时直接按整张图继续。
4. 用户取消选择：不自动抠图，保留原图，可手动填写保存；不阻塞添加流程。

## 三、5(b) 只保留衣物、上下装分开

1. 对输入图跑人体姿态，取置信度 ≥ 0.3 的颈、肩、髋、膝、踝关键点，换算到像素坐标。
2. 上装区域：肩宽左右各留 8% 余量，纵向从颈点上方少量余量到髋点下方；头部、脸、手、腿在几何上被排除。
3. 下装区域：髋宽左右各留 8% 余量，纵向从髋点到踝点（无踝点时到膝下）；用于裤子、裙子、短裤。
4. 用 `VNGeneratePersonSegmentationRequest` 得到人像遮罩，再与上述矩形区域求交，得到「该区域内的人像」透明图。背景、头部、腿部区域外的内容被裁掉。
5. 若关键点不足或分割失败：不做「整个人」抠图，保留原图并提示手动填写（失败回落，不产出人头/人像图）。
6. 上下装都存在时，各自成图、各自作为候选记录；界面提供逐件开关，用户可取消其中一件。
7. 已知限制：袖子、手臂在肩宽之外的像素会被裁掉；短裤/裙子露出的腿部皮肤可能仍在区域内；原生能力无法按肤色/语义逐像素区分「皮肤」与「米色衣物」，因此不宣称 100% 去皮肤。

## 四、5(c) 自动弄平整：方案与预期

**先交方案，再写代码。** 本 PR 采用任务书允许的回落方案，不做生成式补全、不做 3D 重建。

1. 对透明衣物的 alpha 通道求非零像素包围盒，裁掉四周空白，留 6% 内边距。
2. 用 alpha 的二阶中心矩估计主轴角度；上装/外套/一体式按「主轴水平」校正，下装按「主轴垂直」校正，旋转角限制在 ±20°（超过则视为姿态不可靠，不做大角度旋转）。
3. 旋转后再次裁包围盒，等比缩放到长边 1800px（透明 PNG）。
4. 预览与保存都放在浅灰干净底上显示（图片本身保留透明通道），不再带原照片背景。

预期效果：衣物居中、方向基本摆正、无人物和原背景、边缘干净；能明显改善「歪着、带背景、带人」的问题。**不能**消除真实褶皱、不能把叠起来的衣服变成熨平效果；复杂遮挡（包带、手臂压住衣服）仍可能有缺口。达不到完全平铺时，就停在上述「分割 + 裁剪摆正 + 干净背景」，不硬凑。

## 五、5(d) 识别改进

- 主色：只在透明 alpha > 0.5 的衣物像素上统计，背景/草地不再参与。
- 品类：先把透明衣物合成到白底再跑 `VNClassifyImageRequest`，减少透明区域干扰；同时用区域先验（上装区 → 上装/外套；下装区 → 下装）兜底。
- 多件时逐件预填，仍保留「自动识别不一定准确，请自行修改。」。

## 六、条目 6：糊的根源与高清参数

现状根源：
- 导入 `ImageStore.normalizedJPEG`：最长边 1600px、JPEG 质量 0.82。
- 抠图 `saveCutout`：最长边 1000px 透明 PNG。
- 预览/详情读取还会按 600–1200px 缩略，属于显示层，不是源文件。

本 PR 调整：
- 导入：最长边 2560px、JPEG 质量 0.9；单张预估 1.5–3.5 MB（取决于原图细节）。
- 分割：先按原图（必要时先缩到长边 2560）执行，输出透明 PNG 长边 1800px；预估 2–5 MB。
- 低清源图（长边 < 1600px）才显示「本机增强清晰度」开关：Core Image `CIUnsharpMask` + 轻度锐化，纯本机、0 元；可开可关对比，效果只是锐化，不生成新细节。
- 「我的」页照片占用统计已在条目 4 提供，高清后数值会随之变大。

## 七、成本与失败回落

- 成本：0 元。全部为 iOS 原生 Vision / Core Image；无付费 API、无云端、无第三方模型。
- 失败回落：人物检测失败 → 整图继续；姿态/分割失败 → 不做整人抠图，保留原图手动填写；平整失败 → 用未旋转的分割裁剪结果；保存失败 → 提示并保留原图与表单内容。
