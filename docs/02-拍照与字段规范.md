# 拍照与字段规范

> 对应规划书第 7 页（阶段 1）。目标：现有衣物按同一口径录完，求全和准，不求快。

## 1. 拍照规范（1.1）

统一用同一套拍法，后面推荐才不会被照片误导：

1. **平铺**：衣物平铺在床上或干净地面，不挂着拍、不穿在身上拍；
2. **纯色背景**：白墙、浅色床单或一张 A3 白纸，背景不要有花纹；
3. **自然光**：白天靠窗，避免顶灯直射造成的偏色；不要开闪光灯；
4. **一件一张**：不叠放、不摆搭配，配饰单独特写；
5. **深色衣物换浅背景**：黑、藏青、深棕务必用浅色背景，否则轮廓和背景融在一起；
6. 手机举正，衣物占画面 70% 左右，避免广角边缘变形。

**样张要求**：先用 5 件不同材质/颜色的衣物各拍一张，检查三点——颜色接近实物、主体完整、无杂物抢镜。合格后再批量拍。

> 换季补拍时沿用同一背景与光线，避免同一件衣物前后两张色差明显。

## 2. 字段填写规范（1.2）

| 字段 | 必填 | 怎么填 | 示例 |
| --- | --- | --- | --- |
| 名称 | 必填 | 主色 + 品类 + 区分词 | 藏青通勤西裤、米白针织开衫 |
| 图片 | 必填 | 一件一张，按第 1 节拍 | — |
| 品类 | 必填 | 从词表选 | 上装 / 下装 / 外套 / 一体 / 鞋 / 配饰 |
| 主色 | 必填 | 只填面积最大的颜色 | 藏青；拼色在备注写次色 |
| 季节 | 必填（可多选） | 按实际能穿的季节 | 春 + 秋 |
| 厚度 | 必填 | 薄 / 中 / 厚，按实际保暖程度 | 中 |
| 场合 | 必填（可多选） | 至少一个最常用的 | 通勤上班 + 正式场合 |
| 温度区间 | 选填 | 个人体感，例如「15–24℃」 | 与厚度冲突时以本字段为准 |
| 状态 | 必填 | 在用 / 归档 | 归档后保留数据但不参与推荐 |
| 备注 | 选填 | 洗护、搭配禁忌、次色，一句以内 | 不与深色外套同穿 |

**判断口径**（避免同一件衣物两个人填出不同结果）：

- 厚度看「单穿时的保暖程度」，不看面料克重；
- 季节看「你实际会穿它的月份」，不看品牌标注；
- 场合宁可多勾一个，也别漏掉最常用的那个；
- 温度区间不确定就先留空，用厚度兜底。

## 3. 特殊衣物（1.4）

| 情况 | 处理 |
| --- | --- |
| 连衣裙、连体裤 | 品类选「一体」，不算上装+下装；推荐时一套即可成型 |
| 西装套装（外套+裤子） | 拆成两条记录（外套、下装），备注写「与 XX 成套」；推荐时按普通单品参与 |
| 内衣、袜子等 | 不进衣橱（不参与搭配），避免噪音 |
| 两件很像（同款不同色） | 名称加区分词：黑针织衫-薄 / 黑针织衫-厚 |
| 配饰（包、围巾、腰带） | 品类选「配饰」，不参与完整性判断，只影响打分 |

> 一体类衣物在推荐里单独成套，不会再被拆开重复计算。

## 4. 分批录入与逐批核对（1.3）

- 每批 **15–20 件**，录完立刻抽查，不攒到最后一起检查；
- 抽查方法：随机抽 5 件，对照实物核对「图片、名称、品类、主色、季节、场合」；
- 一批抽查有 2 件以上不一致，先停下修正口径，再继续下一批；
- 没录完不要紧，先保证已录的 20 件准确，推荐才有意义。

## 5. 首次导出备份（1.5）

录入全部完成后立刻：

1. 日历与我的 → 我的 → 导出备份；
2. 记下文件名与位置：App 的 `Documents/Backups/衣橱备份-yyyyMMdd-HHmm.zip`；
3. 核对导出说明里的件数与衣橱显示件数一致；
4. 在 `PROGRESS.md` 1.5 的交接备注里写下这次备份的时间与文件名。
